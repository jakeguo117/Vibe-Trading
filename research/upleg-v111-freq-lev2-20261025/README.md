# v1.1.1 锁定快照验收、FREQ、LEV2（2026-10-25）

研究对照，不改实盘路径，不改锁定引擎。数字来自本目录的 `verify_result.json` 与 `freq_lev2_result.json`，没有事后配平。

## 版本与差别

- 基准是 v1.1.1：`k=3`，`cash_floor=0.30`，`gross_cap=0.70`，`vol_target=0.16`，`ma=30`，`exit=halve`，`rank=hist`，常数相关 0.35，流动性成本 5bp / 其余 10bp，份额映射 BRK-A→BRK-B、BH-A→BH。周信号用周五收盘，下一周第二个交易日开盘成交。
- FREQ（`upleg_v111_freq_event_scale`）在上述循环上多两件事，权重 L1 死区仍是 `> 2%`，与日收益阈值不是同一条规则。
  - 已持仓的 Fib 阶段码相对前一日变化，或账上成交品种在信号日 S 的收盘对收盘绝对收益达到 2% 或 3%，于下一根开盘再平衡。2% 与 3% 分两列跑，不是已定参数。
  - 新开仓（不含恢复满仓）按该名额过完波动率目标和总仓上限之后的目标，分三日做到 40% / 70% / 100%，没建完的留在现金。减仓、减半、清仓当次一次做完。分批日即使落在死区内也成交。
- LEV2（`upleg_v111_lev2_etf`）信号、上升段、阶段、排序仍用 GLD / SLV / USO。成交价和 σ 换成 UGL / AGQ / UCO。这三只不进选股池，也不出现在名称表里。其余与 v1.1.1 相同。σ 用两倍序列本身的 EWMA（span 32，`sqrt(252)`），不是把一倍 σ 乘二。

## 规则是否按旁注，以及能不能做纸面并行

旁注里的周节奏、次日开盘成交、商品优先占空位、选股池不含两倍 ETF、减仓一次做完、新仓分批、2% 与 3% 分开，都按上面的实现跑完了。日收益用的是账上成交品种的收盘对收盘，阶段切换用的是信号名的阶段码。分批乘在总仓上限之后，所以没建完的部分留在现金，不会摊给其他持仓。

这组成绩可以做纸面并行的对照：基准已经对上锁定验收；FREQ 两条都跑完，但四舍五入后的年化和最大回撤仍与 v1.1.1 相同，多出来的是成交次数和不到 0.03 的净值差，不能当成已经找到的增益；LEV2 是完整的袖套结果，回撤更深、仓位更低、年化标题为 19.2%。两者都还不是实盘规则替换。
