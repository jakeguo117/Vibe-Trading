## 已有研究的一致性缺口

PR #1，固定版本 `3a6cf21184b535d6f746d84472ff119ab352fe35`：
固定名单代替全市场；排名样本使用均线上涨段而非正本的自然 Fib 主升段，并增加个体胜率同分排序；Sortino 用负收益标准差而非正本的 RMS 下行偏差；期权仍为 Black-Scholes 模型价。其五项门槛不等于 [已批准迭代机制](https://drive.google.com/file/d/1qqEwdlDkC9Lq-bXgzekuqyVKTLkpW6tT/view)的换版门槛。

PR #2，固定版本 `0f282317a41f9b4d4b36d3fe4f23196e02e742b4`：
减半恢复、Fib 阶段、波动估计、目标波动缩放、预算再分配、调仓及成本与正本不同。对同一原始快照，从 2008-01-02 预热并比较 2019-01-02 至 2026-09-30 的 405 个决策周，GLD/SLV/USO 的 Fib 阶段分别有 135/138/123 周不同；全额/半额/空仓状态分别有 4/3/13 周不同。此为逐标的信号诊断，未模拟全市场名额竞争，也不是完整收益重跑。PR #2 的均线比较只能解释它自身那套共同规则，不能等同于正式 v1.1.1 只换均线。
