# v1.1.1 与现金 20% / 总仓 80%（只回测）

值得放进下周的新老陪跑，不要直接换实盘。2023 年起年化从 18.8% 升到 20.4%，这段最深回撤仍是 −11.7%，高点和低点都在 2026-01-29 到 2026-03-26，没有变差。长历史最深的一次仍是 2009-07-10：正本从 1 亏到 0.648（−35.2%），这一档亏到 0.639（−36.1%），大约再深 0.9 个百分点。

只改了两处：现金地板从 30% 改成 20%，总仓上限从 70% 改成 80%。波动目标仍是 16%。没有改实盘，没有改 Mac 上的信号程序，也没有改锁定引擎 `upleg_bt`。
