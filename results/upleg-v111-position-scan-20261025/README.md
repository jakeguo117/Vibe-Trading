怎么读这张表：

- 把总仓从 0.70 放到 1.00，样本内、样本外年化都往上走，是一条坡，不是一根针。样本外回撤从 0.90 开始比正本深。长历史回撤一路更深。

## 仓位被谁吃掉

下面是决策时的目标仓，按天平均。收盘时价格漂过之后的平均仓位会差一点点，正本 2019 起是 0.5915，目标仓平均是 0.5929。这四项加阶段系数，再减去“波动率想加回来的仓”，等于 1 减目标仓。40 组里这条等式的每日最大误差在 1e-15 左右。

2019 起，正本：

| 项目 | 平均吃掉的仓位 | 意思 |
| --- | --- | --- |
| 现金地板 / 总仓上限 | 0.480 | 0.30 是地板本身。另外约 0.18 是波动率想加仓，但 0.70 的总仓把它截住 |
| 波动闸往下砍 | 0.009 | 很少。多数日子目标是想把仓位放大，平均放大 0.412，不是缩小 |
| 离段减仓 | 0 | 减掉的权重按比例还给还在上升段里的名字，总仓几乎不降 |
| 候选不够 | 0 | 三个名额都占得上，商品优先补空位 |
| 阶段系数（这次没扫） | 0.329 | 磨底、震荡、鱼尾没有给满槽 |

所以“把波动目标调高”主要是把已经想加、却被总仓截住的那一段放出来，外加很少的新风险。总仓放到 1.00 之后，这项平均只剩 0.066，目标仓从 0.59 升到 0.71。收益上去了，长历史回撤也更深。

各组三段窗口的这几列都在 `all_results.csv`，列名是 `ate_cash`、`ate_vol`、`ate_exit`、`ate_candidate`，另外有 `ate_stage` 和 `vol_scale_up`。

## 结论

加仓能把 2019 年以后的年化从 18% 往 20% 以上推，这是一整片坡，不是一个碰巧的尖峰。代价是长历史回撤从已经深过 −30% 的 −35.2% 再往下走，样本外回撤也从总仓 0.90 或波动目标 18% 开始比正本差。唯一把长历史回撤收进 −30% 的方向是少拿持仓（k=2）或把均线放到 40 周，这两边的样本外回撤都明显更差。八组把两边拼在一起，仍然没有一组同时过线。

所以不换。继续用 v1.1.1：k=3，现金地板 30%，总仓 0.70，波动目标 16%，30 周均线，离段减半。表里的收益没有扣除退市缺口，2019 后大约每年高 0.3 个百分点，长历史大约每年高 2.4 个百分点。
